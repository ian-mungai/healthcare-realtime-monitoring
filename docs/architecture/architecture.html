Healthcare Realtime Monitoring Architecture

Synthetic FHIR vital signs on AWS: realtime serving path, governed analytical path and recovery, as deployed by the Terraform in infra/

Realtime Path

  • • Simulator publishes FHIR Observations to HAPI FHIR
  • • HAPI rest-hook calls the webhook Lambda, which writes to Kinesis
  • • Processor Lambda keeps latest state in DynamoDB and pushes WebSocket updates
  • • Failed batches go to SQS; one bounded replay, then the dead-letter queue

Analytical Path

  • • Firehose lands raw events in the versioned S3 bucket
  • • MWAA Serverless runs Glue, Athena checks, Great Expectations, dbt, scoring and Soda
  • • Glue merges accepted rows into Iceberg and quarantines the rest
  • • OpenLineage events go to Marquez when enabled, otherwise to S3

Security and Operations

  • • REST and WebSocket clients authenticate with AWS IAM (SigV4)
  • • Webhook secret lives in Secrets Manager; RDS credentials are RDS-managed
  • • CloudWatch alarms notify through a KMS-encrypted SNS topic
  • • GitHub deploys only from main through OIDC and a protected environment
